# DevTools

## Что такое DevTools

DevTools — встроенные инструменты браузера, которые помогают изучать и анализировать работу сайта. С их помощью можно посмотреть HTML, CSS, JavaScript, сетевые запросы, ошибки и временно изменить страницу без изменения исходного кода на сервере.

---

# Elements

## Для чего используется

Вкладка Elements позволяет:

- просматривать HTML-структуру страницы;
- смотреть и изменять CSS;
- временно изменять элементы страницы.

## Что я попробовал

- Изменил текст заголовка.
- Изменил цвет кнопки.
- Удалил элемент страницы.

## Что понял

Все изменения происходят только в моём браузере.

После обновления страницы браузер снова получает оригинальные файлы с сервера, поэтому изменения исчезают.

---

# Console

## Для чего используется

Console показывает:

- ошибки JavaScript;
- предупреждения;
- сообщения (`console.log`);
- некоторые ошибки загрузки ресурсов.

## Что я увидел

На сайте Steam появились ошибки вида:

chrome-extension://...

Позже выяснил, что эти ошибки были вызваны установленными расширениями браузера, а не самим сайтом.

## Что понял

Не каждая ошибка в Console означает, что проблема находится на сайте.

Сначала нужно понять источник ошибки.

---

# Network

## Для чего используется

Вкладка Network показывает все запросы, которые браузер отправляет при загрузке страницы.

Можно увидеть:

- какие файлы загружаются;
- сколько времени занимает загрузка;
- статус каждого запроса;
- размер файлов.

## Что я заметил

На странице Steam:

- около 121 запроса;
- чаще всего встречался статус 200;
- самый большой файл — index.js (~3.3 MB).

## Что понял

Современные сайты загружают большое количество ресурсов.

Большие JavaScript-файлы могут заметно влиять на скорость загрузки страницы.

---

# Что запомнил

- DevTools не изменяет файлы на сервере.
- После обновления страницы изменения исчезают, потому что браузер снова загружает оригинальные данные.
- Console может показывать ошибки не только сайта, но и расширений браузера.
- Network помогает понять, какие файлы загружает страница и как быстро это происходит.
