# Browser DevTools

## 🇬🇧 English

## What is DevTools

Browser DevTools is a built-in set of developer tools available in modern web browsers. It allows developers and QA engineers to inspect web pages, analyze network traffic, debug JavaScript, and temporarily modify page elements without affecting the server.

---

## Elements

### Purpose

The **Elements** tab is used to:

- inspect the HTML structure of a webpage;
- view and edit CSS styles;
- temporarily modify page elements.

### Practice

During practice I:

- changed page text;
- modified button styles;
- removed HTML elements.

### What I learned

All changes exist only inside my browser session.

After refreshing the page, the browser downloads the original files from the server, so every local modification disappears.

---

## Console

### Purpose

The **Console** tab displays:

- JavaScript errors;
- warnings;
- console messages (`console.log`);
- resource loading errors.

### Practice

While testing the Steam website I noticed several errors beginning with:

`chrome-extension://`

After investigation I found that these errors were generated by installed browser extensions rather than by the website itself.

### What I learned

Not every error shown in Console is caused by the website.

Before reporting a bug, it is important to identify the actual source of the error.

---

## Network

### Purpose

The **Network** tab displays every request sent by the browser while loading a webpage.

It helps analyze:

- downloaded resources;
- loading time;
- HTTP status codes;
- request size;
- response size.

### Practice

On the Steam website I observed:

- approximately **121** network requests;
- the most common HTTP status was **200 OK**;
- the largest downloaded file was **index.js** (about **3.3 MB**).

### What I learned

Modern websites load a large number of resources.

Large JavaScript files may significantly affect loading performance.

---

## Key Takeaways

- DevTools does not modify files stored on the server.
- Refreshing the page restores the original content downloaded from the server.
- Console errors may come from browser extensions rather than the website itself.
- Network helps analyze how browsers communicate with servers.

---

## Questions for further study

- How does a browser request files from a server?
- What happens after pressing **F5**?
- What is the difference between HTTP status codes **200**, **301**, **404**, and **500**?

# Browser DevTools

## 🇷🇺 Русский

## Что такое DevTools

Browser DevTools — это встроенный набор инструментов разработчика, который присутствует в современных браузерах. Он позволяет разработчикам и тестировщикам изучать структуру веб-страниц, анализировать сетевые запросы, искать ошибки JavaScript и временно изменять элементы страницы без изменения файлов на сервере.

---

## Elements

### Назначение

Вкладка **Elements** используется для:

- просмотра HTML-структуры страницы;
- просмотра и изменения CSS;
- временного изменения элементов страницы.

### Практика

Во время практики я:

- изменил текст на странице;
- изменил стиль кнопки;
- удалил HTML-элемент.

### Что я понял

Все изменения происходят только в браузере пользователя.

После обновления страницы браузер заново загружает исходные файлы с сервера, поэтому все локальные изменения исчезают.

---

## Console

### Назначение

Вкладка **Console** отображает:

- ошибки JavaScript;
- предупреждения;
- сообщения (`console.log`);
- ошибки загрузки ресурсов.

### Практика

Во время исследования сайта Steam я обнаружил несколько ошибок вида:

`chrome-extension://`

После проверки выяснилось, что их причиной были установленные расширения браузера, а не сам сайт.

### Что я понял

Не каждая ошибка в Console является ошибкой сайта.

Перед созданием баг-репорта необходимо определить настоящий источник проблемы.

---

## Network

### Назначение

Вкладка **Network** отображает все запросы, которые браузер отправляет во время загрузки страницы.

Она позволяет анализировать:

- загружаемые ресурсы;
- время загрузки;
- HTTP-статусы;
- размер запросов;
- размер ответов.

### Практика

Во время анализа сайта Steam я заметил:

- около **121** сетевого запроса;
- наиболее часто встречался статус **200 OK**;
- самым большим загруженным файлом оказался **index.js** (примерно **3.3 MB**).

### Что я понял

Современные сайты загружают большое количество различных ресурсов.

Большие JavaScript-файлы могут заметно влиять на скорость загрузки страницы.

---

## Основные выводы

- DevTools не изменяет файлы, находящиеся на сервере.
- После обновления страницы браузер снова загружает оригинальные данные.
- Ошибки в Console могут быть вызваны не только сайтом, но и установленными расширениями.
- Network помогает понять, как браузер взаимодействует с сервером.
