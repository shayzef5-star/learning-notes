# Responsive Design Mode

## Что это

Responsive Design Mode — инструмент DevTools, который позволяет проверить отображение сайта на разных размерах экранов и мобильных устройствах.

## Для чего используется

- проверка адаптивности сайта;
- поиск UI-багов;
- тестирование мобильной версии.

## Что я попробовал

- открыл сайт Demoblaze;
- переключился между несколькими устройствами;
- проверил расположение кнопок и элементов интерфейса.

## Что понял

Один и тот же сайт может выглядеть по-разному на разных устройствах. QA должен убедиться, что интерфейс остаётся удобным и корректным на всех поддерживаемых разрешениях.
