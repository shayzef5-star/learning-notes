# Storage

## Что это

Storage — инструмент DevTools, который показывает данные, сохранённые браузером.

## Что можно посмотреть

- Cookies
- Local Storage
- Session Storage

## Для чего используется

- проверка авторизации;
- проверка сохранения данных;
- анализ состояния приложения.

## Что я попробовал

Открыл Storage на сайте Demoblaze и посмотрел сохранённые данные после входа в аккаунт.

## Что понял

Некоторые сайты сохраняют информацию о пользователе прямо в браузере, чтобы не требовать повторного входа после обновления страницы.
